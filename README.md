**当前版本：v2.8.1**

「霓虹幸存者」是一款 Vampire Survivors 类的中文弹幕肉鸽游戏。在持续涌来的敌人中移动求生，收集经验、搭配武器与被动，完成普通进化和协同进化，撑过关卡时限与 Boss 波次，还可继续挑战无尽模式。

项目使用纯 Canvas2D 和 vanilla JavaScript 实现，零依赖、零构建。电脑上可直接打开游玩；通过 HTTPS 部署后，还可作为 PWA 安装到手机或桌面。

## 游戏特性

- 10 名角色，拥有不同属性与起手武器池，多数角色还有独立固有机制。
- 21 把基础武器、普通进化以及 32 组协同进化。
- 4 张地图与 4 档难度，包含灼烧、冰封、引力等环境机制。
- 8 种 Boss 行为、周期多 Boss 波、弹幕、旋转激光与专属视觉效果。
- 通关后可选择结算或继续无尽模式。
- 全自动模式：自动走位、避险、拾取与选择升级，可在局内随时开关。
- 键鼠、浮动触屏摇杆和移动端安全区适配。
- 每张地图独立 BGM、合成音效、分项音量控制和移动端音频解锁。
- PWA 离线缓存、动态 iOS 图标和安装后全屏运行。

## 快速开始

### 在线游玩

[打开 GitHub Pages 版本](https://ppp401.github.io/neon-survivor/)

### 本地游玩

下载仓库后双击 `index.html` 即可运行，无需安装依赖或执行构建。

## 操作

| 功能 | 桌面端 | 移动端 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 触屏浮动摇杆 |
| 暂停 / 继续 | `P` | HUD 暂停按钮 |
| 静音 | `M` | 界面音频按钮 |
| 全自动模式 | `O` | HUD 自动模式按钮 |
| 升级选择 | `1` / `2` / `3` | 点击卡片 |

切到后台时游戏会自动暂停；通关时的无尽模式选择和死亡结算始终保留手动确认。

进入游戏后依次选择地图、角色/难度和起手武器，然后开始挑战。武器会自动攻击，玩家主要负责走位、选择升级和决定成长路线。

## 成长与进化

- 基础武器最高 8 级。
- 武器达到 8 级且指定被动达到 5 级后，升级池会出现普通进化。
- 两把指定的已进化武器可合成协同进化武器，并释放一个武器槽位。
- 被动属性可继续升级至 99 级，收益使用递减曲线，避免长局数值无限膨胀。

## 项目结构

```text
.
├── index.html          # 页面结构与经典 script 加载顺序
├── css/styles.css      # DOM 菜单、HUD 与移动端样式
├── js/                # Canvas2D 游戏模块
├── audio/             # 主界面与四张地图的循环 BGM
├── manifest.json      # PWA 元数据
├── sw.js              # 离线缓存与当前版本号
└── icon.svg           # Android/PWA 静态图标
```

JavaScript 模块都使用 IIFE 挂载到 `window.SV`。`index.html` 中的脚本顺序存在严格依赖，以保持无构建且可通过 `file://` 直接运行。平衡数值集中在 `js/config.js`，核心状态机在 `js/game.js`，武器机制在 `js/weapons.js`。
